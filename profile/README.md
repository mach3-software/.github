# The MaCh3 Framework

MaCh3 is a fitting and analysis framework that originated in 2013 as a Bayesian Markov Chain Monte Carlo (MCMC) fitter for the T2K neutrino oscillation analysis. Since then, its functionality and usability have grown substantially, with the framework now supporting analyses for experiments including Hyper-Kamiokande and DUNE.

Official webpage: [https://mach3-software.github.io/MaCh3/](https://mach3-software.github.io/MaCh3/)

# Using MaCh3

The MaCh3 ecosystem consists of several repositories:

* [`MaCh3`](https://github.com/mach3-software/MaCh3) - The Core of the MaCh3 framework, responsible for the fitting algorithms, parameter handling, and reweighting routines.

* [`MaCh3Tutorial`](https://github.com/mach3-software/MaCh3Tutorial) - An introduction to using MaCh3 through a toy pseudo-experiment, with all required inputs provided and ready to use.

* [`MaCh3SbiTools`](https://github.com/mach3-software/MaCh3SbiTools) - Tools for Simulation-Based Inference (SBI) with MaCh3, enabling Bayesian inference techniques beyond traditional MCMC fitting.
